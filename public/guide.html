Overview

The UKSC pipeline watches your personal Telegram for vendor product photos, analyses them with AI, and lets you review, price, and publish products directly to your Shopify store — all from a mobile-friendly web app.

Daily workflow

1
Vendor sends photos on Telegram
Photos land in your personal Telegram — either in a private chat with the vendor, or forwarded to your Saved Messages. The app picks them up within seconds. No action needed on your side.
2
Open the Inbox and tap ↻
Photos appear immediately as pending_analysis. You'll see vendor cards with TG chips showing how many arrived. If a card shows ⚠️ Unassigned, go to Settings → Chat Mapping to link that chat to a vendor.
3
Wait for AI analysis (or run it now)
The AI batch runs automatically every 15 minutes. To process immediately: go to Settings → Run pipeline now. Analysis identifies product type, brand, colours and assigns a confidence level.
4
Review and price products
Switch to the Review tab. Each product card shows thumbnails and AI-filled fields. Set a price (required to publish). Correct any wrong fields. Click ✓ Approve on each card you want to publish.
5
Hit GO to publish
The yellow 🚀 GO bar appears at the bottom once you have approved items. Tap it, then switch to the Queue tab to watch products publish to Shopify in real time.

Telegram ingestion

How the app sees Telegram messages

The app connects to your personal Telegram account (read-only for all vendor chats). It never sends, replies, or reacts in vendor chats. The only outbound message it ever sends is a batch-complete digest to your own Saved Messages.

Photos only arrive after the server starts. The userbot does not back-scan old messages. Only new photos that arrive while the server is running are ingested.

Vendor assignment — how it works

Each photo is assigned a vendor by this priority order:

1
Caption code
If the photo has a caption containing a vendor code (e.g. #siim or #Siim), that vendor wins. Case-insensitive. Must be attached to the photo itself — a separate text message is ignored.
2
Chat mapping
If the chat is mapped to a vendor in Settings → Chat Mapping, all photos from that chat get that vendor automatically — even with no caption.
3
UNASSIGNED
If neither applies, the photo is stored as UNASSIGNED. Map the chat in Settings and all existing unassigned photos from it are retroactively claimed.

Vendor codes

These are the recognised vendor codes. Use them as captions (e.g. #Siim). Partial matches inside words are ignored.

Gallery upload

You can also upload photos manually from the Inbox tab. Select a vendor from the dropdown, then tap Choose photos…. Up to 12 photos at a time. Duplicates (same image already stored) are automatically skipped.

Saved Messages

You can forward WhatsApp vendor photos to your own Telegram Saved Messages and the app will ingest them. Make sure to attach a caption with the vendor code (e.g. #Siim) on each forwarded photo, or map the Saved Messages chat in Settings.

Confidence badges

✓ Good — AI is confident about product type and details. Auto-price rules apply.
⚠️ Low confidence — Blurry photo, multiple products, or unknown type. Review carefully before approving. No auto-price applied.

State badges

📝 needs review No price set yet, or low confidence.
⚡ auto-ready High confidence + auto-price rule matched. Can approve immediately.
✅ approved Ready to publish.
❌ failed Analysis failed — will be re-queued next cycle.

Per-card actions

✕ Skip — Discards the product and marks its photos as skipped. Cannot be undone from the UI.

✓ Approve — Marks the card as approved. A price is required. Once all editing is done, use the GO bar.

Publishing

When at least one card is approved, a yellow 🚀 GO bar appears at the bottom showing how many are approved. Tap it to send them all to Shopify. The app switches to the Queue tab automatically.

Photos arriving within 10 minutes of each other from the same chat are grouped into a single product card (up to 4 images per card). This means a vendor who sends multiple angles of the same item produces one card, not several.

Queue tab

Shows every product in the current publish job. Polls automatically every 3 seconds while the tab is open.

IconMeaning
⏳ (pulsing)Currently uploading to Shopify
✓ (green)Published successfully. Shopify product ID shown.
✕ (red)Failed. Error reason shown inline. Will not retry automatically.
○ (grey)Queued, not yet started

After publishing, the products appear in your Shopify admin as Active (or Draft, depending on your PUBLISH_STATUS setting).

Settings tab

Price rules

Set a default price per product type. When the AI classifies a product with ✓ Good confidence and a matching rule exists, the price is filled in automatically and the card becomes ⚡ auto-ready — no manual pricing needed.

Leave a field blank to disable auto-pricing for that type. Tap Save rules after editing.

Example:
  Trainers    → £ 110
  T-shirt     → £ 45
  Tracksuit   → £ 85
  (others)    → blank = manual price required

Unmapped Telegram chats

Any Telegram chat the app has seen but that isn't linked to a vendor appears here, sorted by photo count. For each chat:

1
Find the chat name
The chat title or display name is shown. This is how the contact appears in your Telegram.
2
Select a vendor from the dropdown
Pick the matching vendor code, or 🚫 IGNORE to permanently silence a chat (e.g. personal contacts, group chats you don't want to scan).
3
Tap Map
The mapping is saved. All existing UNASSIGNED photos from that chat are immediately reassigned to the chosen vendor.
One-time setup per vendor. Once a chat is mapped, all future photos from it are automatically assigned — no captions needed.

Run pipeline now

Triggers the AI batch immediately without waiting for the 15-minute cron. Use this after sending a batch of photos and wanting instant Review cards. A toast notification confirms when it completes.

Log out

Clears your session cookie. The app stays running — just requires the password to log back in. Session lasts 30 days if you stay logged in.

Troubleshooting

Photos sent but nothing in Inbox
1. Tap ↻ to refresh — Inbox only counts today's photos.
2. Check the server is running (the app would show a 401/500 error if it were down).
3. Check if photos arrived as a separate text + separate image messages. The caption must be on the photo, not a separate text.
4. If the chat is not yet mapped, look in Settings → Chat Mapping — the photos are there as UNASSIGNED.
Review tab shows nothing after waiting 15 min
1. Go to Settings → Run pipeline now and check the toast. If it shows an error, the ANTHROPIC_KEY in .env may be missing or invalid.
2. A real Anthropic key starts with sk-ant- and is ~90 characters. Get yours at console.anthropic.com.
3. After fixing the key, restart the server and run the pipeline again.
Vendor showing as UNASSIGNED
Two causes:
A. The photo caption had no vendor code — add #VendorCode as caption directly on the photo (not a separate message).
B. The chat isn't mapped yet — go to Settings → Unmapped Telegram chats and map it. Existing UNASSIGNED photos are retroactively claimed.
GO button does nothing / publish fails
1. Shopify token (SHOPIFY_TOKEN in .env) may be missing or invalid. It must be a Shopify Admin API access token from Settings → Apps → Develop apps.
2. SHOPIFY_DOMAIN must be your store's myshopify.com domain (e.g. yourstore.myshopify.com).
3. After fixing, restart the server. Check the Queue tab for the specific error message.
App asks for password every time
The session cookie lasts 30 days. If you're being asked on every visit, check that your browser isn't blocking cookies for localhost, and that you're accessing the app over HTTP (not HTTPS) locally.

Re-running Telegram login

If the userbot fails with session invalid/expired, run:

node scripts/login.js

Follow the prompts (phone number → confirmation code → 2FA password if set). Copy the printed session string into .env as TELEGRAM_SESSION, then restart the server.
